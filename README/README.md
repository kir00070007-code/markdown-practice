# Мой учебный репозиторий

Есть момент, когда учёба перестаёт быть просто списком задач и превращается
в историю. Этот репозиторий — как раз такая история: здесь собираются
домашние задания, практики и проекты, которые я делаю по курсу. Каждая папка —
это маленький шаг вперёд, а каждый коммит — строчка в дневнике программиста.

## Содержание

1. Домашние задания
2. Практики
3. Проекты

## Как использовать

Откройте нужную папку и изучите файлы внутри. Если вы здесь впервые —
начните с домашних заданий: они как первые страницы книги, с которых
удобнее всего начать читать. Практики покажут, как теория превращается
в код, а проекты — это уже самостоятельные главы, где всё складывается
воедино.

## Портфолио по программированию

Здесь будут собраны мои учебные проекты. Пока это только начало пути,
но у каждого большого проекта когда-то был свой первый коммит.
